# Dota Lens 0.4.2

Dota Lens 0.4.2 的重点是让本地 Replay 解析更快、更稳，并把复盘结论收束成普通玩家
能快速看懂、硬核玩家可以继续展开证据的报告。

## 本次更新

- 同场 Replay 旧流程约 `105.8 秒`，优化后常见复盘约 `20-27 秒`。
- 20 万级原始事件样本首次解析约 `40.6 秒`，命中本地缓存后约 `26.6 秒`。
- 大型 JSONL 改用字段投影读取，摘要采用列式编码，原始逐秒事件继续保存在压缩归档中。
- Replay 任务新增阶段耗时、缓存复盘、过期解析器自动重启和任务结束内存回收。
- 玩家报告升级到 V3，增加分位置评分、优缺点、根因链、阶段结论和可展开证据。
- 发育复盘增加逐单位兵线与野怪生命周期、20 分钟后核心路线审计和更严格的安全路线门禁。
- 视野分析增加坐标稳定的鼠标滚轮缩放、眼位生命周期和连续敌方可见性证据。
- 战斗复盘补强开战前 10 秒、职责硬门禁、主战场定位以及阵亡、物品延误、目标损失与视野缺口的同源合并。
- 调整全局字号、可折叠侧栏、紧凑比赛头部、战斗和视野模块布局。
- 移除整套人工标注工作流及未再使用的分类器运行时代码。

## 安装

1. 下载 `Dota-Lens-Setup-0.4.2-x64.exe`。
2. 运行安装程序并选择安装目录。
3. 启动 Dota Lens，输入 Steam 32 位数字 ID。
4. 选择比赛并确认解析，等待本地 Replay 复盘完成。

安装包已包含 Java 运行时，普通用户无需单独安装 Node.js、Java 或 Maven。

## 已知限制

- 安装程序尚未使用商业代码签名，Windows SmartScreen 可能显示未知发布者。
- 当前仍使用 Electron 默认应用图标。
- 比赛列表和 Replay 元数据依赖 OpenDota；没有可下载 Replay 的比赛无法完成逐秒复盘。
- 不同 Dota 2 Patch 的 Replay 字段可能变化，部分结论会在证据不足时降级为估算或不输出。
