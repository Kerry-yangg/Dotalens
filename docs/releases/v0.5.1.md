# Dota Lens 0.5.1 更新说明

0.5.1 是 Replay 兼容性修复版本，解决部分新比赛录像下载完成后仍在 49% 解压阶段失败的问题。

## 修复内容

### 新格式 Replay 无法解析

- 修复有效录像被错误提示为“录像文件损坏或下载不完整”。
- 修复技术错误 `Stream is not in the BZip2 format`。
- 不再根据 `.dem.bz2` 文件名强行使用 BZip2，而是读取文件内容识别真实压缩格式。
- 同时支持原始 DEM、传统 BZip2 和 Valve 当前返回的 Zstandard Replay。
- 手动导入的压缩录像也会使用相同的格式检测，不再因扩展名与内容不一致而拒绝导入。

### 玩家报告稳定性

- 加固玩家报告关键时刻的简明文本渲染，避免特定报告内容导致页面无法完成显示。
- 桌面端冒烟截图会等待玩家报告和团战图表真正渲染完成，减少“页面打开但内容尚未加载”的误判。

## 原因说明

OpenDota 的录像下载地址仍可能使用 `.dem.bz2` 文件名，但比赛 `8918837931` 返回的实际内容是 Zstandard 压缩帧。旧解析器只按文件名调用 BZip2 解压，因此把一份完整有效的录像误判成损坏文件。

0.5.1 改为读取文件头特征后选择对应解压器：

- `PBDEMS2`：原始 DEM
- `BZh`：BZip2
- `28 B5 2F FD`：Zstandard

## 验证结果

- 真实比赛 `8918837931` 已完成下载、解压、解析和玩家报告生成。
- 共生成 `202,001` 条有效事件。
- 完整前端、工具、桌面端与解析器自动化测试通过。
- Windows 安装包内置解析器已确认包含 Zstandard 解压支持。

## 安装

在 Dota Lens `0.5.0` 中打开“设置 → 软件更新”即可检查 `0.5.1`。

也可以直接运行：

`Dota-Lens-Setup-0.5.1-x64.exe`

安装包仍未进行代码签名，Windows 可能显示 Microsoft Defender SmartScreen 提示。
