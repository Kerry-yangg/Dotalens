# Dota Lens 0.5.0 更新说明

0.5.0 的重点不是再加一张图，而是让分析真正回答：这局哪里做得好、哪里出了问题、为什么，以及应该回看哪一波。

## 主要更新

### 玩家报告 4.0

- 简明模式使用大白话覆盖整局优点、问题、关键事实和训练建议。
- 专业模式展开十个维度、评分依据、职责门禁和技术证据。
- 不再固定只讲三个阶段，所有通过证据门禁的重要时刻都会进入报告。
- 每条可执行结论均可跳转到对应时间、地图、团战、打钱、视野或出装窗口。
- 按 1/2/3/4/5 号位使用不同职责和建议，不再给所有位置相同文案。
- 合并同一根因造成的阵亡、装备延误、目标损失和视野缺口，避免重复扣分。

### P1 发育与路线证据

- 兵线交汇点、塔前安全区和推进深度。
- 购买、信使送达和物品首次可用的完整时间。
- 神符收益、辅助离线收益、疑似拉野和等级强势期利用。
- 缺少战争迷雾或逐单位证据时只给“建议复核”，不会假装知道唯一最优路线。

### 本地 Replay

- 本地 Replay 继续支持高分对局和公开接口找不到录像的场景。
- OpenDota 暂时不可用时，可以使用缓存比赛列表和本地录像分析。
- 解析失败页会显示可理解的原因、解决建议和反馈信息。

### 使用体验

- 首次启动默认打开使用说明，并提供操作截图。
- “简明 / 专业”阅读模式移到明显位置并自动记忆。
- 比赛列表可自定义读取 1 至 500 场，默认 20 场。
- 移除独立的“完整时间轴”和“数据覆盖”页面；必要时间轴和核心事实保留在分析模块内。
- 视野地图支持缩放，1024 宽度下筛选文字也能完整显示。
- 任务历史在重启后保留。

## 安装

运行：

`Dota-Lens-Setup-0.5.0-x64.exe`

安装包已经包含 Java 和本地解析器，不需要另外安装运行环境。

## 使用提醒

- 在线读取比赛列表前，请确保 Dota 2 个人资料公开比赛数据。
- 8500 分以上或公开接口没有录像时，建议在 Replay 页面手动导入 `.dem` 或 `.dem.bz2`。
- 安装包目前没有代码签名，Windows 可能显示 SmartScreen 提示。
- 大型 Replay 解析时内存峰值可能接近 2 GB，建议电脑至少有 8 GB 内存。
