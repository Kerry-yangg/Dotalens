# Dota Lens 0.4.3

Dota Lens 0.4.3 是一次可信度与桌面闭环修复，重点解决跨模块结论、误导文案、任务留痕和上游故障降级。

## 本次更新

- 修复对线 `major_advantage` 与 `major_disadvantage` 在玩家报告中的错误映射。
- 增加对线、故事、简报和评分方向的一致性回归测试。
- 修复资源倒计时浮点残差，并区分 Replay Patch 与资源规则基线。
- 修正战斗视野覆盖和兵线波次文案。
- 最近 20 个解析任务支持本地持久化，刷新后可恢复活动任务。
- 删除未接真实行为的设置，新增 Parser、Java、内存和数据目录诊断及脱敏导出。
- 数据覆盖页说明哪些结论可确认、受影响或已被抑制。
- OpenDota 异常时自动使用最近一次账号比赛缓存，本地 Replay 与已有报告继续可用。
- 新增 PowerShell 7 EXE 功能冒烟和布局冒烟脚本。

## 已知限制

- OpenDota 离线列表需要至少一次成功同步缓存。
- 任务历史当前保存在应用本地，尚未迁移到 Parser 中心账本。
- 1024x720 下打钱和视野地图首屏仍偏小。
- 隔离环境首次完整解析约 58 秒，后续将专项优化 JSON 体积、首屏加载和冷解析。
- 当前安装包没有商业代码签名，仍使用 Electron 默认图标。
