# Dota Lens 0.5.9

发布日期：2026-09-08。适用于 Windows 10/11 x64。

## 主要更新

- **更容易打开本机报告**：比赛页、Replay 列表和已完成任务均可直接打开已保存的报告，无需先连接账号。首次使用提供游戏 ID、导入录像和本机报告三个入口。
- **本局总结优先**：打开比赛默认显示原有“一页复盘”；“深度分析”和“分析思路”作为独立页签。分析思路可从结果回查前序交战、死亡状态与候选解释，再逐段打开证据。
- **更完整的团战复盘**：提供整场个人团战报告和跨局统计；地图两侧展示双方十人生命、魔法与状态，地图较窄时自动调整布局。
- **开团前视野对照**：支持天辉、夜魇和上帝视角，以及开团前 10 秒、前 5 秒和交战开始定位。切换阵营保留当前时间；模拟覆盖、录像确认和覆盖来源分别说明。
- **更清楚的结论与数字**：简明模式优先说明游戏事实和可回看的动作，技术详情按需展开。本路结果与个人执行分开显示，统计范围、单位、报告状态和缺失数据有明确说明。
- **证据往返更稳定**：从本局或跨局报告查看具体片段后，返回时保留对应页签、筛选、样本和阅读位置。重复切换已查看的团战会复用缓存。

## 修复

- 修复关键帧内容长短变化造成地图、播放条上下跳动；长说明在卡片内滚动。
- 调整紧凑窗口的团战地图与分析页签布局，避免 1280 像素宽度下报告内容挤压和横向溢出。
- 修复点击报告正文或展开依据时误触阅读模式刷新、依据随即收回的问题。
- 修复证据尚在加载时跳到第一场战斗或错误打钱片段的问题。
- 修复首次打开报告后立即切换深度分析或页签时，报告模块尚未加载而触发的渲染错误。
- 修复跨局战斗胜负与比例在不同区域口径不一致、缺失值显示为 `null` / `undefined%` 等问题。
- 补齐报告读取失败后的重试入口，修复 PNG 分享导出及 HTML 报告英雄图片缺失。

## 已知限制

- 安装包尚未进行商业代码签名，仍使用 Electron 默认程序图标；Windows SmartScreen 可能显示未知发布者。
- 视野属于基于录像事实的模拟重建。模拟覆盖不等于录像确认，不能据此直接认定玩家看见敌人或应承担责任；特殊技能、隐身及缺失的地形状态仍可能影响结果。
- 分析思路提供可核对的事实与候选解释，不自动认定“本来可以支援守住”，也不因新入口而把历史报告升级为已核验。
- 部分旧分析包可能缺少新模块；首次读取完整团战视野仍可能需要等待。密集时间轴节点及部分小窗口控件仍有后续优化空间。
- 自动比赛查询与 Replay 获取依赖 OpenDota 和 Valve；无法公开获取的录像仍需参赛者手动导入。
