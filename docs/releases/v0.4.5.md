# Dota Lens 0.4.5 本地候选版

> 状态：本地构建与验收通过，暂不发布 GitHub  
> 桌面端：`0.4.5`  
> 本地 API：`1.6.0`

## 版本范围

0.4.5 的正式验收范围只包含“可信本地 Replay 导入闭环”：

- 校验 Replay 内部比赛 ID，错误文件名不会污染其它比赛。
- 使用 Steam 账号自动匹配本场玩家。
- 账号不在十人名单时要求手动选择，不再默认第一位玩家。
- 手动选择结果按比赛持久化，Parser 重启后仍能恢复。
- Patch 来源区分确认、时间推断、边界不确定和未知。
- Patch 不确定时关闭依赖 Patch 的地图、技能和负向评分门禁。
- `.dem` 与 `.dem.bz2` 可以在 OpenDota 不可用时完成本地导入和分析。
- 用户源 Replay 不会被重命名或删除。

## 随包预览

当前开发工作区同时包含以下 0.5.0 预览能力：

- 玩家报告结论定位与有界回放。
- 战斗时机行为诊断第一阶段。
- 十人贡献镜像图、当前团战/全场切换和五维雷达下钻。

这些预览能力不计入 0.4.5 的完成门槛，也不代表 `player-report/4.0`
或 0.5.0 已经完成。0.5.0 仍需完整评分链、缺失事件生产器和 15 场五位置回归。

## 本地验收门槛

- 前端、桌面端和 Parser 全量自动测试通过。
- 真实 Replay 离线 E2E 不跳过。
- 安装包内 Parser API 为 `1.6.0`。
- 固定 Replay 完成自动匹配、手动选择、重启持久化和 Patch 来源验证。
- 错误 Match ID 返回结构化错误，且不删除用户源文件。
- EXE 完成安装、启动、取消、完整解析、冷重启和卸载。
- 关键页面完成 1024x720、1280x800、1460x920 和可用最大桌面视口检查。

## 当前限制

- 安装包没有商业代码签名。
- 应用仍使用 Electron 默认图标。
- OpenDota 首次离线且没有本地缓存时无法显示在线比赛列表。
- 多 Patch 地图、复杂战争迷雾和技能元数据仍需扩大真实 Replay 回归。
- 0.5.0 玩家报告协议和长期多场训练尚未完成。

## 发布决定

本轮只生成本地安装包和验收报告，不创建 Git 标签、不推送分支，也不创建 GitHub
Release。验收完成后继续在当前开发分支实施 0.5.0。
